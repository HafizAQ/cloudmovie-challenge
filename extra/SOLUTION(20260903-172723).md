# CloudMovie Challenge - Complete SOLUTION Documentation

## Project Overview

CloudMovie Challenge is a production-oriented cloud engineering capstone
project that deploys an interactive movie-guessing web application on
AWS.

The final solution demonstrates:

-   Infrastructure as Code using Terraform
-   AWS networking architecture
-   Containerized application deployment
-   Secure container registry management
-   Serverless AWS Lambda integration
-   Secrets management
-   Monitoring and alerting
-   CI/CD automation

------------------------------------------------------------------------

# Solution Architecture Overview

The complete implementation consists of the following layers:

## Application Layer

-   CloudMovie web application

# Solution 1: Core AWS Infrastructure Deployment

## 1. Application Features

Implemented application functionality:

-   Home page to start the challenge
-   Interactive movie guessing game
-   Leaderboard page
-   DynamoDB-based score persistence

------------------------------------------------------------------------

# 2. AWS Networking Architecture

The project uses a custom VPC architecture.

Implemented components:

-   VPC
-   Four subnets across two Availability Zones
-   Public subnets
-   Private subnets
-   Route tables
-   Internet Gateway
-   NAT Gateway
-   Elastic IP
-   Security groups

This design separates public-facing resources from private application
resources and follows a production-style cloud networking pattern.

------------------------------------------------------------------------

# 3. Compute and Load Balancing

## EC2

The application runs on an EC2 instance inside the private subnet.

The instance communicates with users through the Application Load
Balancer.

## Application Load Balancer

The ALB provides:

-   Internet-facing access
-   Multi-AZ deployment
-   Traffic distribution
-   Health monitoring

## Target Group

The target group:

-   Uses HTTP port 5000
-   Registers application instances
-   Confirms healthy application availability

------------------------------------------------------------------------

# 4. Database Layer

Amazon DynamoDB is used for leaderboard storage.

Configuration:

-   Table: cloudmovie-challenge-dev-leaderboard
-   Partition key: player_id
-   Encryption enabled
-   Application writes leaderboard data successfully
