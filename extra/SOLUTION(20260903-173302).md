# CloudMovie Challenge - Complete SOLUTION

## Project Overview

CloudMovie Challenge is a production-oriented cloud engineering capstone
project that deploys a movie-guessing web application on AWS.

The final solution combines:

- AWS networking architecture
- EC2-based application hosting
- Application Load Balancer
- DynamoDB persistence
- AWS Lambda serverless functionality
- Secrets Manager integration
- CloudWatch monitoring and alerting
- SNS notifications
- Terraform Infrastructure as Code
- Docker containerization
- Amazon ECR image management
- GitHub Actions CI/CD automation

This document combines all implementation evidence from Solution 1,
Solution 2 and Solution 3 into one complete project solution guide.

---

# 1. Application Architecture

## Application Features

The CloudMovie application provides:

- Home page
- Emoji-based movie guessing game
- Leaderboard functionality
- Persistent score storage using DynamoDB

The application architecture follows this flow:

User
↓
Application Load Balancer
↓
EC2 Application Instance
↓
DynamoDB Leaderboard Database

Additional services:

- Lambda for serverless bonus functionality
- Secrets Manager for secure credentials
- CloudWatch for monitoring
- SNS for alert notifications
